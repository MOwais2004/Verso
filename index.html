01 — What it does

AI that runs the picture desk

Verso looks at every frame, writes down what is in it, and keeps that description on the file — so the archive answers to a sentence instead of a folder name.

Ø1 / Describe

It writes down what the picture is

Subject, light, location and lens, in the words you would have used yourself. Nine hundred frames from one setup collapse to the six worth showing, the rest one click away.

Ø2 / Protect

Rights travel on the frame

Licence and expiry live on the file, so an image that cannot run tells you before you send it. Read-only by default — nothing copied, nothing re-encoded, and no frame of yours trains a model.

Ø3 / Keep up

Twenty years, read in a weekend

The first pass on a hundred thousand frames takes about a day, and after that it keeps up in real time — wherever the work already lives. Drives, Dropbox, an old NAS in the corner.
